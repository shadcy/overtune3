\section*{1. System Overview \& Hardware Requirements}

\textbf{Overtune 3} (\texttt{ot3}) is a high-precision digital filter design and live audio simulation workstation built on pure C++20 and Qt 6. It features automated Stage 2 compliance mathematical audits, sub-millidecibel magnitude precision, and SIMD-accelerated cascaded biquad evaluation.

\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item \textbf{Linux Requirements:} Any modern 64-bit Linux distribution (Ubuntu 22.04+, Fedora 38+, Arch Linux, Debian 12+) with GLIBC 2.34+ and Qt 6.4+ libraries.
  \item \textbf{Windows Requirements:} Windows 10 (64-bit, 1809+) or Windows 11 (x64) with Microsoft Visual C++ 2022 Redistributable.
  \item \textbf{Display:} Minimum recommended display resolution of $1280 \times 800$ with HiDPI display scaling support.
\end{itemize}

\section*{2. Linux Installation \& Execution}

Overtune 3 provides three straightforward deployment methods on Linux platforms:

\subsection*{Method A: Native Automated Setup (\texttt{install\_linux.sh})}
The interactive installer integrates \texttt{ot3} into your desktop environment, creates desktop and application menu entries, registers icons, and links the CLI binary:
\begin{lstlisting}[language=bash]
# User-level installation (No root required - installs to ~/.local/share/overtune3)
./scripts/install_linux.sh

# System-wide installation (Installs to /opt/overtune3 and /usr/local/bin)
sudo ./scripts/install_linux.sh
\end{lstlisting}
Once completed, launch Overtune 3 from your application menu or directly run \texttt{ot3} from any terminal.

\subsection*{Method B: Standalone Portable Shareware Bundle}
For zero-install portable deployment (e.g., from a USB drive or local directory):
\begin{lstlisting}[language=bash]
tar -xzf overtune3-linux-x86_64.tar.gz
cd overtune3-linux-x86_64
./ot3.sh
\end{lstlisting}

\subsection*{Method C: Building from Source}
\begin{lstlisting}[language=bash]
./build.sh                  # Builds optimized release binary in ./build/bin/ot3
./build/bin/ot3             # Direct launch
\end{lstlisting}

\section*{3. Windows Installation \& Execution}

Overtune 3 provides comprehensive native Windows deployment options designed for both standard desktop users and power users:

\subsection*{Method A: One-Click Executable Installer (\texttt{ot3-installer.exe})}
The most convenient native deployment option:
\begin{enumerate}[leftmargin=20pt,itemsep=2pt]
  \item Double-click \texttt{ot3-installer.exe} directly from the distribution package.
  \item The installer GUI opens automatically, allowing custom selection of target installation directory, Desktop shortcut creation, and Start Menu registration.
  \item Click \textbf{Install Overtune 3} to finalize deployment in seconds.
\end{enumerate}

\subsection*{Method B: Standalone Portable Shareware Package (Zero Install)}
For instant, portable execution without administrative rights or registry modifications:
\begin{enumerate}[leftmargin=20pt,itemsep=2pt]
  \item Extract \texttt{shareware\textbackslash windows\textbackslash overtune3-windows-x64.zip} (or copy the \texttt{overtune3-windows-x64} directory).
  \item Double-click \texttt{ot3.bat} or \texttt{run.bat} to launch the application immediately.
  \item Alternatively, navigate to \texttt{bin\textbackslash} and execute \texttt{ot3.exe} directly.
\end{enumerate}

\subsection*{Method C: Automated Native PowerShell Installer (\texttt{install\_windows.ps1})}
To integrate Overtune 3 into Windows via command line or automated IT scripts:
\begin{lstlisting}
# Standard user or Administrator execution:
powershell -ExecutionPolicy Bypass -File .\shareware\windows\install_windows.ps1
\end{lstlisting}

\textbf{Supported Options \& Switches:}
\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item \texttt{-InstallDir <path>}: Target folder (defaults to \texttt{\%LOCALAPPDATA\%\textbackslash Programs\textbackslash Overtune3}).
  \item \texttt{-NoDesktop}: Skip creating the Desktop shortcut.
  \item \texttt{-NoStartMenu}: Skip creating the Start Menu shortcut.
\end{itemize}

What the installer accomplishes:
\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item Copies the complete application bundle including all required Qt 6.7 runtime libraries, QML engines, multimedia backends, and assets.
  \item Creates the \textbf{Desktop} shortcut (\texttt{Overtune 3.lnk}) and \textbf{Start Menu} entry (\texttt{Programs\textbackslash Overtune 3}).
  \item Registers \textbf{Overtune 3 Studio} in Windows Settings $\rightarrow$ \textit{Installed Apps} with an uninstallation hook.
  \item Prepares \texttt{overtune\_update.bat} for atomic background updating.
\end{itemize}

\subsection*{Method D: Building from Source on Windows (\texttt{build.bat})}
If building from repository sources using Visual Studio 2022 and Qt 6:
\begin{lstlisting}
# One-click configure, compile, and runtime deployment:
.\build.bat

# Direct launch:
.\run.bat
\end{lstlisting}

\subsection*{Windows Uninstallation}
To remove Overtune 3 cleanly from the system:
\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item \textbf{In-App Uninstallation (Recommended):} Open Overtune 3 $\rightarrow$ click \textbf{Settings} (gear icon in sidebar) $\rightarrow$ scroll to \textbf{System Integration \& Uninstall} $\rightarrow$ click \textbf{Uninstall Overtune 3}. The application cleanly deletes shortcuts, unregisters from Windows registry, schedules self-directory removal, and exits gracefully.
  \item \textbf{Windows Settings:} Open \textbf{Windows Settings} $\rightarrow$ \textbf{Apps} $\rightarrow$ \textbf{Installed Apps} $\rightarrow$ \textbf{Overtune 3 Studio} $\rightarrow$ \textbf{Uninstall}.
  \item \textbf{PowerShell Script:} Run \texttt{powershell -ExecutionPolicy Bypass -File "\%LOCALAPPDATA\%\textbackslash Programs\textbackslash Overtune3\textbackslash uninstall.ps1"}
  \item \textbf{Batch Script:} Double-click \texttt{"\%LOCALAPPDATA\%\textbackslash Programs\textbackslash Overtune3\textbackslash uninstall.bat"}
\end{itemize}


\section*{4. In-App Auto-Updater \& In-Place Atomic Updates}

Overtune 3 features a unified OLED modal updater window matching the What's New and Stage 2 Verifier interfaces. It handles live patch updates seamlessly:

\begin{itemize}[leftmargin=20pt,itemsep=3pt]
  \item \textbf{Accessing Updates:} Select \textbf{Help $\rightarrow$ Check for Updates...} or click the \textbf{Installer / Update Ready} badge in the titlebar.
  \item \textbf{Linux Atomic Patching:} Leverages POSIX atomic \texttt{unlink}/\texttt{rename} semantics. The running application binary is replaced smoothly in place without requiring process termination before write.
  \item \textbf{Windows Detached Updater:} Bypasses Windows executable file-locking by spawning a detached helper script (\texttt{overtune\_update.bat}) that waits for the parent process PID to exit cleanly, replaces \texttt{ot3.exe} with \texttt{ot3.exe.new}, and restarts the updated studio application.
  \item \textbf{Cryptographic SHA-256 Audit:} All downloaded payload chunks are validated against release cryptographic checksums before application.
\end{itemize}
