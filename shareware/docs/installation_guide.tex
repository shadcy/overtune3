\section*{1. System Overview \& Hardware Requirements}

\textbf{Overtune 3} (\texttt{ot3}) is a high-precision digital filter design, audio simulation, and DSP study workstation built on modern C++20 and Qt 6. It features automated mathematical audits, sub-millidecibel magnitude precision, SIMD cascaded biquad evaluation, and interactive DSP Chat assistance.

\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item \textbf{Windows Requirements:} Windows 10 (64-bit, 1809+) or Windows 11 (x64) with Microsoft Visual C++ 2015--2022 Redistributable.
  \item \textbf{Linux Requirements:} Any modern 64-bit Linux distribution (Ubuntu 22.04+, Fedora 38+, Arch Linux, Debian 12+) with GLIBC 2.34+ and Qt 6.4+ libraries.
  \item \textbf{Audio \& Display:} DirectSound or WASAPI audio output device; minimum $1280 \times 800$ resolution with HiDPI support.
\end{itemize}

\section*{2. Windows Installation \& Deployment}

Overtune 3 provides four convenient installation and execution options on Windows:

\subsection*{Method A: Standalone Native Installer (\texttt{ot3-installer.exe})}
The dedicated graphical setup wizard handles complete deployment with no admin rights required:
\begin{itemize}[leftmargin=20pt,itemsep=2pt]
  \item Run \texttt{ot3-installer.exe} (or \texttt{Overtune3-Setup-x64.exe}) from \texttt{dist/}.
  \item Configure target destination (defaults to \texttt{\%LOCALAPPDATA\%\textbackslash Programs\textbackslash Overtune3}).
  \item Automatically creates Start Menu and Desktop shortcuts and registers in Windows \textbf{Installed Apps}.
\end{itemize}

\subsection*{Method B: Standalone Portable ZIP (Zero Installation)}
Extract \texttt{overtune3-windows-x64.zip} to any folder. Run \texttt{run.bat} or \texttt{bin\textbackslash ot3.exe} directly. All Qt 6 libraries, QML modules, codecs, and fonts are self-contained.

\subsection*{Method C: Automated PowerShell Setup (\texttt{install\_windows.ps1})}
For automated, unattended, or CI/CD deployments:
\begin{lstlisting}
powershell -ExecutionPolicy Bypass -File .\scripts\install_windows.ps1
\end{lstlisting}
Optional flags: \texttt{-InstallDir "C:\textbackslash Path"}, \texttt{-NoDesktop}, \texttt{-NoStartMenu}.

\subsection*{Method D: Compiling from Source}
\begin{lstlisting}
build.bat                 # Configures CMake, compiles Release, deploys Qt runtime
run.bat                   # Runs the newly compiled release binary
\end{lstlisting}

\section*{3. Linux Installation \& Execution}

\subsection*{Method A: Native Automated Setup (\texttt{install\_linux.sh})}
\begin{lstlisting}[language=bash]
./scripts/install_linux.sh          # User-level (~/.local/share/overtune3)
sudo ./scripts/install_linux.sh     # System-wide (/opt/overtune3)
\end{lstlisting}

\subsection*{Method B: Standalone Portable Bundle}
\begin{lstlisting}[language=bash]
tar -xzf overtune3-linux-x86_64.tar.gz && cd overtune3-linux-x86_64 && ./ot3.sh
\end{lstlisting}

\section*{4. In-App Updates, AI Assistant \& Clean Uninstallation}

\begin{itemize}[leftmargin=20pt,itemsep=3pt]
  \item \textbf{In-App Updates:} Access \textbf{Settings $\rightarrow$ Updates} and click \textbf{Check}. Downloads are verified against release SHA-256 hashes.
  \item \textbf{AI DSP Assistant (Shadcy):} Configure OpenRouter model IDs and API keys in \textbf{Settings $\rightarrow$ AI Assistant}. On Windows, keys are encrypted securely using the Windows DPAPI.
  \item \textbf{Uninstallation:} Click \textbf{Uninstall} in \textbf{Settings $\to$ Resources \& Maintenance}, via Windows \textbf{Settings $\to$ Apps $\to$ Installed apps}, or execute:
  \lstinline[basicstyle=\footnotesize\ttfamily]!%LOCALAPPDATA%\Programs\Overtune3\uninstall.bat!
\end{itemize}
